# Planowanie eksperymentów (DoE) na przykładzie mikrootworów

Samodzielny plik `index.html`: 8 rozdziałów, ściąga w 10 krokach i słowniczek; wszystkie obliczenia w przeglądarce, wykresy z Plotly 2.35.3 (cdnjs, wymaga internetu). Dane to wyniki symulacji makro projektu lamp (stal 304, układ heksagonalny, 0,4–0,5 mm), wbudowane w plik. Powstał z Claude (Claude Code); kod źródłowy i opis: krzyszur/websites, `lampy/web/nauka-doe/` i `lampy/scripts/nauka_doe/`. Testy: Playwright + Chromium.
